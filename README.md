# hello-github

这是我第一个 GitHub 仓库。**「仓库」就是一个文件夹**，只是它会记住你的每一次修改。

## 你现在看到的是什么

- 页面地址是 `github.com/funknnna/hello-github`
- `funknnna` 是你的账号，`hello-github` 是这个文件夹的名字
- 页面中间列出来的，就是文件夹里的文件（现在只有一个 `README.md`）

## README 是什么

README 是这个文件夹的**说明书**。任何人打开一个仓库，第一眼看到的就是它。

不需要学任何语法，就当写普通文字。你现在读的这段，本身就是 README。

## 几个词，一次讲一个

| 词 | 人话 |
|:--|:--|
| 仓库 Repository | 一个文件夹，会记住每次改动，改坏了能退回 |
| README | 这个文件夹的说明书，也是它的「门面」 |
| Commit 提交 | 一次「存档」，附一句说明改了什么 |
| Push 推送 | 把本地改动上传到 GitHub |
| Issue | 一张便利贴：记录「这里有 bug」或「我想要这个功能」 |
| Pull Request | 改完了，申请把改动合并进来 |

## 我该做的第一件事

改掉下面这一行里的一个字，然后存档（commit）。

原来的句子是：**这是我的第一个仓库。**

（把它改成你自己的话。你会在页面上看到一条新的历史记录——这就是 GitHub 唯一的魔法，其余都是它的延伸。）
